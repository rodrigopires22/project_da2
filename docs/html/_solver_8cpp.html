Solution solveBruteForce ( const Dataset & dataset)

Resolve o problema da seleção de paletes utilizando o algoritmo de força bruta.

Resolve o problema da otimização usando força bruta.

Gera todas as combinações possíveis de paletes (2^n) e seleciona aquela que oferece o maior lucro, respeitando a capacidade máxima do camião.

Parameters
datasetEstrutura contendo a capacidade do camião e a lista de paletes.
Returns
Solution Estrutura contendo o lucro total, peso total e as paletes selecionadas.
Note
Complexidade temporal: O(2^n * n), onde n é o número de paletes (devido à enumeração de subconjuntos).
Complexidade espacial: O(n), para armazenar a seleção atual e a melhor seleção.

Solution solveGeneticAlgorithm ( const Dataset & dataset)

Resolve o problema da seleção de paletes utilizando um algoritmo genético.

Resolve o problema da otimização utilizando um algoritmo genético.

Algoritmo evolutivo que simula a seleção natural. Mantém uma população de soluções candidatas e aplica cruzamento e mutação para evoluir soluções melhores.

Parameters
datasetEstrutura contendo a capacidade do camião e a lista de paletes.
Returns
Solution Estrutura contendo o lucro total, peso total e as paletes selecionadas.
Note
Complexidade temporal: Aproximadamente O(G * P * n), onde G é o número de gerações, P é o tamanho da população, e n é o número de paletes.
Complexidade espacial: O(P * n), para armazenar a população.

Solution solveGreedy ( const Dataset & dataset)

Resolve o problema da seleção de paletes utilizando uma abordagem gulosa.

Resolve o problema da otimização usando uma abordagem gulosa.

Ordena as paletes com base na razão lucro/peso e as seleciona enquanto houver capacidade. Não garante uma solução ótima, mas é eficiente e útil para grandes conjuntos de dados.

Parameters
datasetEstrutura contendo a capacidade do camião e a lista de paletes.
Returns
Solution Estrutura contendo o lucro total, peso total e as paletes selecionadas.
Note
Complexidade temporal: O(n log n), devido à ordenação das paletes.
Complexidade espacial: O(n), para armazenar os objetos ordenados.
