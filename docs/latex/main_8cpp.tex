\doxysubsection{Detailed Description}
Ponto de entrada principal para o Otimizador de Paletes. 

Permite ao utilizador carregar datasets e escolher entre diferentes algoritmos de otimização para selecionar paletes com base em lucro e peso, respeitando a capacidade do caminhão.

Função principal do programa. 

Esta função permite ao utilizador\+:
\begin{DoxyItemize}
\item Carregar datasets de paletes;
\item Visualizar os dados carregados;
\item Selecionar e executar um dos algoritmos disponíveis;
\item Observar os resultados (lucro total, peso total e paletes selecionadas), assim como o tempo de execução.
\end{DoxyItemize}

Algoritmos disponíveis\+:
\begin{DoxyItemize}
\item Força Bruta\+: Garante solução ótima, mas com complexidade exponencial O(2\texorpdfstring{$^\wedge$}{\string^}n).
\item Programação Dinâmica\+: Solução ótima com complexidade O(n \texorpdfstring{$\ast$}{*} W), onde W é a capacidade do caminhão.
\item Guloso\+: Solução aproximada com tempo linearithmic O(n log n), baseada em razão lucro/peso.
\item Algoritmo Genético\+: Solução heurística com tempo dependente de parâmetros (gerações, população, etc).
\end{DoxyItemize}

\begin{DoxyReturn}{Returns}
int Código de saída do programa (0 se encerrado com sucesso).
